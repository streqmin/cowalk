# 서촌 가을 산책 — 식사 · 카페 · 구경

경복궁 서쪽 서촌 일대의 식당·카페·구경거리를 세 카테고리로 정리한 단일 HTML 페이지입니다.
외부 의존성 없이 `index.html` 하나로 동작합니다 (폰트만 Google Fonts에서 불러옵니다).

## 기능

- 카테고리 탭(전체 / 식사 / 카페 / 구경)과 해시 라우팅 (`#meal`, `#cafe`, `#see`)
- 장소 카드: 이름, 일러스트, 주소, 운영시간, 대기 전망, 태그, 설명
- 손으로 그린 SVG 약도 — 핀을 누르면 해당 카드로 이동, 카드에서 핀 강조
- 「현재 위치에서 길찾기」: Google Maps 도보 경로 (기기 현재 위치 → 목적지), 카카오맵 링크
- 「내 위치 표시 · 거리순 정렬」: 위치 권한 허용 시 약도에 내 위치 표시, 카드별 도보 거리/분, 가까운 순 정렬
- 모바일 적응형 레이아웃, 바텀시트 지도, `prefers-reduced-motion` 대응

## 사용

`index.html`을 브라우저에서 열거나, GitHub Pages 등 정적 호스팅에 올리면 됩니다.

## 참고

- 운영시간·전시 정보는 2026년 11월 7일 기준이며 방문 전 확인을 권합니다.
- 실제 사진 대신 일러스트를 사용하며, 카드의 「사진 보기」가 네이버 지도의 사진으로 연결됩니다.
